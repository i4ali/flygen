# Onboarding Edit Demo Implementation Plan

> **For Claude:** Owner preferences override the default template: NO TDD (build-verify only,
> owner eyeballs the simulator), NO branches (work on main), NO commits unless explicitly asked.
> Design: `docs/plans/2026-07-19-onboarding-edit-demo-design.md`.

**Goal:** Extend the onboarding auto-demo to also show flyer editing - the sent edit message,
the ticking checklist, and the updated flyer - before the interactive beats.

**Architecture:** The onboarding is a data-driven beat list (`OnboardingScript.beats`) walked by
`ChatOnboardingViewModel`. All needed beat types already exist; we insert five beats and teach
`DemoFlyerReveal` to present a single card (it currently assumes three).

**Tech Stack:** SwiftUI, iOS app only. No engine changes, no new Swift files (so no pbxproj edits).

### Task 2: Single-card mode for DemoFlyerReveal

**Files:**
- Modify: `FlyGen/FlyGen/Views/Onboarding/DemoFlyerReveal.swift`

A lone card currently renders side-card sized (88pt) and tilted 18°. Make a solo card centered,
untilted, and slightly larger than the three-up middle card.

**Step 1:** Add a computed property to `DemoFlyerReveal`:

```swift
    private var solo: Bool { imageNames.count == 1 }
```

**Step 2:** In the `ForEach`, replace the `mid`-based modifiers so a solo card gets the hero
treatment without the fan offsets:

```swift
                ForEach(Array(imageNames.enumerated()), id: \.offset) { idx, name in
                    let hero = solo || idx == 1
                    DemoFlyerCard(name: name, sweep: shown, reduceMotion: reduceMotion)
                        .frame(width: solo ? 124 : (hero ? 104 : 88))
                        .rotation3DEffect(.degrees(shown ? fanAngle(idx) : 0),
                                          axis: (x: 0, y: 1, z: 0), perspective: 0.6)
                        .scaleEffect(shown ? (hero ? 1.06 : 1.0) : 0.9)
                        .offset(y: shown ? (hero && !solo ? -10 : 0) : 26)
                        .opacity(shown ? 1 : 0)
                        .zIndex(hero ? 1 : 0)
                        .animation(reduceMotion ? nil
                                   : FGAnimations.springBouncy.delay(Double(idx) * OnboardingTiming.revealStagger),
                                   value: shown)
                }
```

**Step 3:** Guard the fan angle:

```swift
    private func fanAngle(_ idx: Int) -> Double {
        guard !solo else { return 0 }
        return idx == 0 ? 18 : (idx == 2 ? -18 : 0)
    }
```

The `DemoFlyerCard` BBQ placeholder is correct for the edit card too - it is still the BBQ flyer.
