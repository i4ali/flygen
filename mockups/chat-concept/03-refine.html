7 Failure without anxiety
AI image gen still garbles text occasionally. Today a bad render burns 10 paid credits; here the assistant detects, apologizes and retries silently — subscriptions absorb the cost psychology.
The honest splitWords → tap-edit (structured text re-rendered instantly, no AI). Design → chat (AI edit pass on the existing image, ~15–25 s). The UI never pretends an AI pass is instant — the canvas shows which kind of change is happening.
Maps to current backendThe pipeline already supports image+prompt edit mode ("preserve everything except…"), aspect-ratio re-renders, and post-gen QR/logo compositing. The chat is a new front door to capabilities that exist today.
